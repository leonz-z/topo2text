This network topology represents a hybrid architecture. Key components include the UCI Core Network, LBDC Router, MSTB Router, ADC Router, ASA 5520 Firewall, and the main.ucop Mainframe. These components are connected via routers and firewalls, facilitating secure communication and data transfer. The overall structure supports distinct user groups, such as Internet Users, Campus Users, and OIT Developers, ensuring efficient data flow and access to critical services. Notable features include secure access to production servers and development environments, enhancing the network's reliability and functionality.
