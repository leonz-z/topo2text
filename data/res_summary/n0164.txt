This network topology represents a hybrid architecture. Key components include the Root Bridge, Switch 1, Switch 2, and the Root Port (RP), connected via Gigabit Ethernet interfaces (Gi1/2, Gi1/1, Gi1/3). The overall structure supports efficient data flow and redundancy through the use of the Spanning Tree Protocol (STP). Notable features include blocked links to prevent loops, ensuring efficient communication between the switches and the root bridge.
