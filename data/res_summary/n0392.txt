This network topology represents a hybrid architecture. Key components include access switches (A1-1, A1-2, A1-3), distribution switches (D1-1, D1-2, D2-1, D3-1), and core switches (C1-2). These are connected via Layer 2 802.1Q trunks, facilitating VLAN traffic across the network. The overall structure supports efficient communication and routing between multiple VLANs across three buildings. Notable features include the use of Switched Virtual Interfaces (SVIs) for inter-VLAN routing and redundancy measures, ensuring reliable data flow and network segmentation for various departments and functions.
