This network topology represents a hybrid architecture. Key components include the OpenStack Control Node, Neutron AFC Plugin, Asteria Fabric Controller, MP-BGP EVPN, and VTEPs, connected via RESTful APIs and various networking protocols. The overall structure supports scalable and efficient data flow within a virtualized environment. Notable features include centralized management through the Asteria Fabric Controller and support for VM migration, ensuring efficient communication between virtual machines and the underlying physical network.
