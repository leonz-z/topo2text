This network topology represents a hybrid architecture. Key components include core switches SW_6509_1 and SW_6509_2, and several edge switches (SW_2950 series) such as SW_2950_edge, SW_2950_fi1, and SW_2950_server. These are connected via Ethernet links. The overall structure supports efficient data flow and redundancy, allowing for communication across various VLANs dedicated to different departments (e.g., financial, technical, sales) and server access. Notable features include VLAN segmentation for enhanced security and performance, ensuring efficient communication between user groups and services.
