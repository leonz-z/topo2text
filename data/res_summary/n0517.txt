This network topology represents a hybrid architecture. Key components include the Intersite Network (ISN), spine switches, leaf switches, Application Policy Infrastructure Controllers (APICs), and the Multi-Site Orchestrator (MSO) Cluster, connected via high-speed links and OSPF support. The overall structure supports efficient data flow and centralized management across multiple data centers. Notable features include high availability and scalability, ensuring seamless communication between virtual machines and other endpoints across Data Center 1 and Data Center 2.
