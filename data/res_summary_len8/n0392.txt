This network topology represents a **hybrid topology** architecture. Key components include **access layer switches (A1-1, A1-2, A1-3, A2-1, A2-2, A2-3, A3-1, A3-2, A3-3)**, **distribution layer switches (D1-1, D1-2, D2-1, D2-2, D3-1, D3-2)**, and **core layer switches (C1-1, C1-2)**, connected via **Layer 2 trunks and Layer 3 routing**. The overall structure supports **efficient data flow and VLAN segmentation** across different buildings. Notable features include **high availability and redundancy**, ensuring efficient communication between **various departments and services** within the network.
