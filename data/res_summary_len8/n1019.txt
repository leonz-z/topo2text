This network topology represents a star architecture. Key components include the TP-Link AC100 V4.0 router, TP-Link SG1210PT switches, multiple TP-Link access points (AX1800 and AX1908GI), an IPTV device, and a Synology NAS (DS920+). These components are connected via Ethernet cables, facilitating data flow between the internet, streaming services, and local devices. The overall structure supports efficient communication and resource sharing among devices. Notable features include centralized management through the router and switches, ensuring high availability and scalability for user connectivity and data access.
