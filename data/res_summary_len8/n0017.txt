This network topology represents a hybrid architecture. Key components include the vEdge-3 device, ISP-1, and ISP-2, connected via underlay and overlay segments. The underlay segment consists of the physical connections to the ISPs, while the overlay segment utilizes interfaces Ge0/0 and Ge0/1 on the vEdge-3 for secure and optimized data transmission. The overall structure supports efficient communication between internal networks and external internet resources, ensuring redundancy and high availability. Notable features include the ability to manage traffic dynamically and implement security measures, enhancing the network's reliability and performance.
