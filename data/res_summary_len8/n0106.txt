This network topology represents a hybrid architecture. Key components include routers (R1, R2), switches (SW-2L-1, SW-2L-2, SW-3L-1, SW-3L-2), and firewalls (FW1, FW2). The devices are connected via Ethernet and Gigabit Ethernet links. The overall structure supports efficient data flow and security across different network segments. Notable features include redundancy and access control, ensuring secure communication between end-user devices and core network resources.
