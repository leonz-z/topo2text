This network topology represents a hybrid architecture. Key components include routers (AR1, AR3, AR4, AR7), switches (LSW1, LSW2), a DHCP server, and a web server. The connections are primarily facilitated through Ethernet links and inter-switch connections. The overall structure supports efficient data flow and redundancy across various network segments, including core, branch, and VLAN segments dedicated to specific functions like administration, dormitories, and academic departments. Notable features include dynamic IP address allocation via the DHCP server and web hosting capabilities, ensuring robust communication between user groups and services.
