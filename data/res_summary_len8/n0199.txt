This network topology represents a star architecture. Key components include the Ubuntu Virtual Servers, the Attacker, Client 1, and Client 2, connected via a firewall that separates the Untrusted Network, DMZ Network, and Trusted Network. The overall structure supports secure communication and service delivery, with the DMZ hosting services like HTTP, FTP, and VoIP. Notable features include a robust security framework to mitigate threats from the Attacker, ensuring efficient communication between trusted clients and the servers.
