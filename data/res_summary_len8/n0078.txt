This network topology represents a hybrid architecture. Key components include the UCI Core Network, LBDC Router, ASA 5520 Firewall, MSTB Router, ADC Router, and various servers (e.g., db1.oit.uci.edu, Web1.oit.uci.edu, alpha.oit.uci.edu). These components are connected via routers and firewalls, facilitating secure communication and data flow. The overall structure supports efficient communication between different user groups, including campus users and OIT developers, while ensuring security through the ASA 5520 Firewall. Notable features include segmented network segments for distinct purposes and high availability, ensuring robust access to resources and services.
