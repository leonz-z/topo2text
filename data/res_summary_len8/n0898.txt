This network topology represents a star architecture. Key components include the Huawei Fiber Modem, Ubnt Edge Router, multiple switches (Huawei Switch, Huawei Switch2, hiWiFi Switch, TP Switch1, TP Switch2), and a CLOUD segment. The devices are connected via Ethernet cables and wireless connections, with the Ubnt Edge Router serving as the central hub that manages data flow between the local network and the internet. The overall structure supports efficient communication and resource sharing among connected devices, including workstations and cloud services. Notable features include the integration of wireless access through the hiWiFi Switch and the potential for network segmentation, ensuring secure and reliable connectivity for users and devices.
