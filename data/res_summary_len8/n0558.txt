This network topology represents a hybrid architecture. Key components include the Telecom Room, Security Gateway, Web Server, Resource Server, Core Switch, Secondary Switch Line 1, Secondary Switch Line 2, Dormitory, Dining Hall, and Academic Building. The nodes are connected via switches and routers, facilitating efficient data flow and resource sharing. The overall structure supports communication among various user groups, ensuring high availability and scalability. Notable features include network segmentation and redundancy, enhancing performance and security across the network.
