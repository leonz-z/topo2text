This network topology represents a hybrid architecture. Key components include a central switch (中心交换机), firewall (防火墙), web server (WEB 服务器), FTP server (FTP 服务器), and multiple secondary switches (二级交换机). The devices are connected via Ethernet switches, facilitating communication between various segments of the network. The overall structure supports efficient data flow and resource sharing, ensuring secure access to web and file services for users across different locations, including classrooms and administrative offices. Notable features include a robust security layer provided by the firewall and the ability to accommodate a diverse range of user devices, ensuring scalability and high availability.
