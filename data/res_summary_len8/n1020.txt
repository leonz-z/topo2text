This network topology represents a hybrid architecture. Key components include core routers (SJZ-CA-BR-1 and SJZ-CA-BR-2), border switches (SJZ-CA-BS-1 and SJZ-CA-BS-2), an access switch (SJZ-CA-SG-AS-1), a local internet access router (本地互联网接入路由器), and access switches (办公区接入交换机). These components are connected via various types of connections, including Ethernet and direct links to internet service providers. The overall structure supports efficient data flow and connectivity between internal and external resources. Notable features include redundancy and segmentation, ensuring high availability and security for user devices and services within the network.
