This network employs a hybrid architecture, primarily designed to facilitate communication and resource sharing within an educational environment. Its core nodes include: routers, firewalls, switches, a core switch, a library, application servers, a web server, and a DNS server, interconnected and collaborating closely. For instance, the router interacts with the firewalls and the core switch via direct connections, responsible for managing external and internal traffic; the core switch connects to multiple switches and firewalls, enabling efficient data routing; the switches connect to the library, application servers, web server, and DNS server, facilitating access to resources; and the library connects to student and faculty networks through the switches, allowing users to access information and services. These nodes are linked through data dependencies and collaborative dependencies. Overall, this topology aims to provide a clear understanding of the network's structure, aiding in troubleshooting, planning, and optimizing network performance within the educational institution.
